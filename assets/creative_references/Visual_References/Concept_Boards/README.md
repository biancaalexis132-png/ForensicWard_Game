# Concept boards: superseded, do not model

`ashcroft_concept_board_1.png` and `ashcroft_concept_board_2.png` are early mood boards. They are kept for history only.

They contradict canon: names and roles are scrambled (for example "Dr Adrian Bennett", "Warden Marcus Mercer"), the setting is the 1980s–90s, patients are tied to Ward Zero, and board 2 lists real actors as likeness references. Never use them for faces, wardrobe, roles or ages.

Current direction: `docs/design/CHARACTER_VISUAL_CANON.md`.
