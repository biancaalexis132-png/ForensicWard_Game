## Intended use

This package is intended as concept-direction material for The Forensic Ward.
It should guide environment art, lighting, prop selection, signage, scene dressing, and supernatural event staging for Ward Zero.

## Direction notes for Claude

- Treat Ward Zero as a decommissioned lower-level forensic ward beneath Ashcroft State Forensic Hospital.
- Preserve clinical realism in the modern hospital while making Ward Zero visually older, colder, and more industrial.
- The supernatural dimension is real, but it should be introduced subtly at first.
- Early anomalies should read as environmental and temporal inconsistencies, not as proof that a patient's psychiatric symptoms are supernatural.
- Repeating spaces, conflicting timestamps, reflection mismatches, and duplicate object placement are preferred early anomaly cues.
- Material language: pale institutional green, dirty beige, oxidized metal, concrete gray, fluorescent white, wet black reflections, and shadow blue.
