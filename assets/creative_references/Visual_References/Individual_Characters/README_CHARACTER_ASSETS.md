## Art handoff requirements
- Generate **new original character models**; these images are guidance, not riggable 3D assets or exact front/side/back turnarounds.
- Before modeling, approve each face, hairstyle, clothing silhouette and skin-tone/material palette. Do not infer ethnicity from the generated concept alone.
- Deliver for each character: front, 3/4, profile and back orthographic views; neutral pose; 5 facial expressions; wardrobe and prop close-ups; consistent lighting and scale.
- Patients must be represented respectfully. Psychiatric symptoms, diagnosis, credibility and supernatural activity must never be encoded in exaggerated visual stereotypes.
- Avoid directly copying real people's likenesses. Document origin/licensing for all eventual game-ready artwork.
- Claude: review against the latest game design bible; do not replace existing characters blindly and do not merge asset changes automatically.
