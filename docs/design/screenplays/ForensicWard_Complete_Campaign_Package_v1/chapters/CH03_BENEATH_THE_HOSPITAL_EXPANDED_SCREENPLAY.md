# CHAPTER 3 — BENEATH THE HOSPITAL
## Expanded end-to-end playable screenplay | production draft v1.0

> **Status:** Proposed narrative/production manuscript. Not a shipped Godot runtime or a clinically approved treatment simulation. Source baseline: GitHub five-chapter draft and later Chapter 2–5 creative expansions.

## Chapter intent
First authorized entry yields preliminary measurement concerns, explicitly short of proof or the corridor-loop reveal.

## Scene 01 — A Legitimate Reason to Go Down
**Location:** Operations office
**Function:** Written Security and Facilities authorization defines purpose, team, entry route, check-in cadence, stop triggers and return criteria.

### Screenplay & blocking
**HALE**: This is an inspection, not a tour.  
**PLAYER**: I’m here to verify records within my authorized role.  
**FACILITIES**: We stop if the route, communications or exit conditions change.  

### Player choices (all preserve required access)
- **A.** Confirm escort roster
- **B.** Review stop conditions
- **C.** Check return plan

**Scene exit / continuity:** Proposed inspection gate; no forced entry until all checks pass.
